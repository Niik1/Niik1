### 🚀 Sobre mí                                                                                                                            
                                                                                                                                               
Soy **Ingeniero de Sistemas Computacionales** y **Desarrollador de Software Full Stack**. Me especializo en diseñar e implementar aplicaciones web modernas, reactivas y escalables, combinando interfaces de usuario fluidas con arquitecturas de backend y bases de datos robustas.     

                                                                                                                                               
Cuento con experiencia demostrada en el ciclo completo de desarrollo de software (*End-to-End*):                                           
* **E-Commerce & Plataformas SaaS:** Creación de plataformas full-stack (Next.js 16, TypeScript, Supabase) integrando pasarelas de pago (**Mercado Pago con webhooks asíncronos**).                                       
* **Automatización y Pricing Retail:** Desarrollo de motores financieros reactivos para fijación de precios omnicanal en 17 marketplaces, eliminando hojas de cálculo complejas y reduciendo tiempos de cálculo a sub-milisegundos.                                                  
* **Sistemas Empresariales & Escritorio:** Desarrollo de software de gestión comercial, inventario y facturación en **C# (.NET) y SQL Server**.                                                                                                                                  


Mi formación en ingeniería de software y análisis de datos me permite abordar cada proyecto con un enfoque centrado en la calidad del código, el tipado estricto, la seguridad y la solución de problemas reales de negocio.
